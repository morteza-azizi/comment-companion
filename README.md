# Comment Companion

A lightweight browser extension for inserting reusable comments across community platforms.

## Features

- Random comments
- Comment categories
- Local storage
- Browser based
- No cloud dependencies

## Supported Platforms

| Platform | Status |
|----------|---------|
| Vivino | ✅ |
| LinkedIn | Planned |
| GitHub Discussions | Planned |
| Reddit | Planned |
